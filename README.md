# File Operator Project (Python)

A menu-driven CLI (Command Line Interface) Python application for basic file handling operations.

---

## 📌 Features

- **Create File**: Create a new text file.
- **Write File**: Overwrite or add initial content to a file.
- **Read File**: Display the content of an existing file.
- **Append Data**: Add new content to the end of a file without overwriting existing data.
- **Rename File**: Change the name of an existing file.
- **Delete File**: Safely delete a specified file.
- **Error Handling**: Checks if a file exists before attempting to read, rename, or delete.

---

## 💻 Tech Stack

- **Language**: Python 3.x
- **Module Used**: `os` (built-in)
